# Weather2Go: Route Radar

Weather2Go: Route Radar is a Michigan-focused machine learning project that predicts driving risk based on weather conditions at a trip's starting point and destination.

## MVP

Users will:

* Enter a start location and destination in Michigan
* View the route on a map
* Retrieve weather conditions for both locations
* Receive a **Low, Medium, or High** driving-risk prediction for each location
* See one overall trip risk based on the higher of the two predictions

## Project Status

Early development. This repository is a clean rebuild focused on reproducible modeling, validation, and a clearer application workflow.

## Project History

Weather2Go has evolved through several iterations:

* [Weather2Go SpartaHack 11](https://github.com/RayofData/Weather2Go_Spartahack11) — Original hackathon version that introduced the weather-based driving-risk concept.
* [Weather2Go2](https://github.com/RayofData/Weather2Go2) — Follow-up modeling work focused on improving the machine learning approach and validation.
* **Weather2Go: Route Radar** — Clean rebuild that combines the predictive model with route mapping and start/destination weather.
